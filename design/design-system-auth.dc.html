Componentes (mapeo 1:1 a primitivas shadcn)

Button → shadcn Button, variant default, size default

44px alto, radius md, texto 14px/600. Hover #E56700. Focus: anillo 0 0 0 3px color-mix(in oklch, primary, white 65%). Disabled: bg #FFD3AD, sin interacción. Loading: spinner 14px a la izquierda del label, botón deshabilitado mientras dura.

Input → shadcn Input

Ingresa un correo válido.

Errores por campo van bajo el input, nunca en el banner genérico — el banner de formulario solo se usa para el error de credenciales (mensaje siempre genérico, nunca decir cuál campo falló).

Alert → shadcn Alert, variantes custom warning/destructive/success

Warning — sesión expirada
Error — credenciales inválidas
Success — sesión cerrada

Card → shadcn Card

Contenedor base — usado por el card de login. Radius lg (14px), padding 40px 36px en el login real, ancho máx. 400px.

Badge — RoleGate (B.5, nuevo) → shadcn Badge, variante por rol
